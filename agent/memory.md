line per entry, dated, with where it came from and, when it is only true for
a while, an expiry:

The bot reads it on every turn, after the house rules. It holds how to do
this job here — which tool answers which question, what this clan calls
things, what a brief should have said, what the operator wants kept in mind.
It never holds a fact about the game (Elixir has those), and never anything
about a person.

Keep it short: every line here is paid for on every turn. Expired lines are
skipped automatically. The review prunes turn-cited entries nothing has
needed in a month; it never touches what the operator said. Delete a line to
forget it.
